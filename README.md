# Aplikasi-Kasir-dan-Cashflow-SAPRIMA
POS Kasir &amp; Cashflow untuk UMKM

## Isi repo

- `index.html`: aplikasi web Tera Kasir (dideploy ke Vercel).
- `sw.js`: service worker supaya aplikasi tetap bisa dibuka saat offline.
- `supabase/schema.sql`: tabel database dan Row Level Security.
- `supabase/README.md`: langkah menyiapkan Supabase dan mengisi data contoh.
